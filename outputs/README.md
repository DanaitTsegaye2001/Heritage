# outputs/

Generated by the pipeline; everything here except this file and `.gitkeep` is git-ignored
and reproducible from `storyboard.json` with `make film`.

```
outputs/
  script/      script.md · narration.txt · timeline.json
  keyframes/   s01.png …            (+ .meta.json cache sidecar per artifact)
  shots/       s01.mp4 …            (video model or Ken Burns fallback)
  narration/   s01.wav …
  music/       cue_<id>.wav
  assemble/    mix.wav · clips/<16x9|9x16>/sNN.mp4 · overlays/
  final/       heritage_16x9.mp4 · heritage_9x16.mp4 · heritage.srt · report.json · storyboard.snapshot.json
```

Each `*.meta.json` records `input_hash` (what produced it) and `output_hash` (its bytes).
Delete a single artifact (or its sidecar) to force just that piece to regenerate.
